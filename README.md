# Self-Hosted Cloud

Собственная инфраструктура облачного хранилища на базе Nextcloud и DevOps-инструментов.

## О проекте

Цель проекта — создать и поддерживать собственную платформу облачного хранения файлов, используя современные DevOps-практики и инструменты автоматизации.

## Используемые технологии

- **Nextcloud** — платформа для хранения и обмена файлами.
- **Docker** — контейнеризация приложений.
- **Docker Compose** — управление многоконтейнерной инфраструктурой.
- **PostgreSQL** — система управления базами данных.
- **Redis** — кэширование и управление блокировками файлов.
- **Nginx** — веб-сервер и обратный прокси.
